# Terraform Associate (004) class

Labs, one folder per session: `labs/session-NN/`. Start with that
session's `README.md`.

Credentials never go in files: export `VSPHERE_SERVER`, `VSPHERE_USER`,
`VSPHERE_PASSWORD` and `VSPHERE_ALLOW_UNVERIFIED_SSL=true` in your shell.
`terraform.tfvars` and state files stay on your laptop (see `.gitignore`).
